## What it is
Gitgather is a small social hub for developers built **entirely on GitHub** — no servers, no database, no paid services:

| Feature | Powered by |
|---|---|
| Website (installable PWA, dark/light) | GitHub Pages — vanilla HTML/CSS/JS, no build step |
| Sign in | Your GitHub account via [giscus](https://giscus.app) |
| Project posts | GitHub Discussions in the **Show and tell** category, with a form template |
| Likes & comments | Discussion reactions 👍 ❤️ 🚀 🎉 and comments, embedded with giscus |
| Stars & follows | Real GitHub stars / follows — the site links straight to the repo or profile |
| Top 100 · 24h | GitHub Action (hourly) → `data/top100.json` |
| Profiles | Public GitHub REST API + the user's Gitgather posts |
| Chat | Public rooms (Lobby, Help, Show & Tell) = pinned discussions in **General** |

## Post your project
1. Open **[New showcase post](https://github.com/DanMo88/gitgather/discussions/new?category=show-and-tell)**.
2. Fill in the form: repo URL, short title, description, tags, optional screenshot.
3. It appears on the site within about an hour (or right after a maintainer runs the workflow).

## How the Top 100 · 24h is scored
Every hour `.github/workflows/leaderboard.yml` runs `scripts/build-data.mjs`, which reads the Showcase discussions through the GraphQL API using the built-in `GITHUB_TOKEN` and counts only activity from the **last 24 hours** (by reaction/comment timestamps):

```
score = 3   × comments & replies   (max 3 per person, author's own excluded)
      + 2   × unique people who reacted to the post (author excluded)
      + 0.5 × reactions on the post's comments
      + 0.5 × new stars on the repo  (capped at 10 stars)
      + 1   if the post is less than 24h old
```
Conversation is weighted above stars on purpose, so star swapping doesn't pay. **Star-for-star trading is against [GitHub's Acceptable Use Policies](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies) and our [Code of Conduct](CODE_OF_CONDUCT.md).**

## Project layout
```
index.html  post.html  chat.html  profile.html   # pages
assets/      app.js style.css logo.svg icons/     # UI
data/        posts.json top100.json               # generated by the Action
scripts/     build-data.mjs                       # scoring (Node 20, no deps)
.github/     workflows/leaderboard.yml  DISCUSSION_TEMPLATE/show-and-tell.yml
```

## Limits
- The leaderboard refreshes **hourly** (and on new/edited posts).
- Profiles use the unauthenticated GitHub API (**60 requests/hour per visitor**, cached per session).
- Chat is **public** (it's GitHub Discussions). There are no private messages.
- Sign-in and commenting need the giscus GitHub App installed on this repo.

See [MODERATION.md](MODERATION.md) for maintainer tools.

## 🇮🇷 معرفی به فارسی

**Gitgather** یک «پاتوق» برای اهالی گیت‌هاب است؛ یک شبکهٔ اجتماعی کوچک که **همه‌چیزش روی خود گیت‌هاب اجرا می‌شود** — بدون سرور، بدون دیتابیس و بدون هزینه.

- **ورود:** با همان اکانت گیت‌هاب خودت وارد می‌شوی (از طریق giscus).
- **معرفی پروژه:** روی «Post your project» بزن، فرم کوتاه را پر کن تا پروژه‌ات در سایت نمایش داده شود.
- **لایک و نظر:** واکنش‌ها (👍 ❤️ 🚀 🎉) و کامنت‌ها مستقیم داخل سایت ثبت می‌شوند.
- **استار و فالو:** استار و فالو واقعیِ گیت‌هاب هستند؛ سایت مستقیم به ریپو یا پروفایل لینک می‌دهد.
- **۱۰۰ پروژهٔ برتر ۲۴ ساعت گذشته:** یک GitHub Action هر ساعت امتیاز پست‌ها را بر اساس نظرها و واکنش‌های ۲۴ ساعت اخیر حساب می‌کند. استارها وزن کمی دارند تا «تبادل استار» بی‌فایده باشد.
- **چت:** اتاق‌های گفتگوی عمومی (Lobby، Help، Show & Tell). توجه: **چت عمومی است** و همه می‌توانند آن را ببینند؛ پیام خصوصی وجود ندارد.

لطفاً مهربان باش، اسپم نکن و درخواست «استار بده، استار می‌دم» نگذار — این کار خلاف قوانین گیت‌هاب است.
